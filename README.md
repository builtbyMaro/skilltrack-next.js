# SkillTrack

SkillTrack is a learning platform concept inspired by platforms like Udemy and Coursera, designed to help users access structured learning experiences across different skill categories.

Built with a focus on authentication flows and scalable UI architecture, the project simulates a real-world educational platform experience.

---

## 🚀 Features

- User authentication system (Login, Signup, Password Reset)
- Protected and public route structure
- Clean and reusable form components
- Responsive UI for multiple devices
- Scalable page structure for future learning modules

---

## 🧠 Purpose of the Project

SkillTrack was built to practice real-world frontend architecture patterns such as:

- Authentication flow handling
- Component reusability
- Page protection logic
- Multi-page application structure

---

## 🛠️ Tech Stack

- Next.js
- React
- CSS Modules
